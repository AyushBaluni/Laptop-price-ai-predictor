4. Project Files

laptop_price.csvReal dataset — 1,303 laptops, prices in INR. Sourced from Kaggle (CampusX / idealo.de 2019).
train_model.pyRidge regression training script. Pure Python stdlib — no pip dependencies. Outputs model_coeffs.json.
model_coeffs.jsonTrained model coefficients (32 values), test metrics (R², MAPE, RMSE), and dataset provenance.
inspect_data.pyColumn audit: price range, missing values, categorical distributions.
verify_model.pyLoads dataset + coefficients, confirms price range, runs a manual prediction check.
laptop_price_predictor.htmlComplete single-file web app. All CSS + JS inline. No internet connection or build step required.
server.jsMinimal Node.js static server (optional — app works via file:// directly).
qa_full.mjsBrowser automation QA script — tests 3 realistic configs, takes full-page screenshot.
screenshot_result.pngVerified screenshot: MSI Gaming config showing ₹1,04,823 prediction with feature impact bars.
requirements.txtPython dependency declaration (stdlib only; optional scikit-learn/pandas noted).
README.mdProject documentation, quick start, model details, sample predictions, disclaimer.
